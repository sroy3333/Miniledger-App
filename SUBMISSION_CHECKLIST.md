# Submission checklist

- [ ] Install dependencies and run the backend against PostgreSQL.
- [ ] Run the Expo app on a simulator or phone.
- [ ] Test OTP from server logs, add a loan, show overdue state, and mark one repaid.
- [ ] Push the `miniledger` folder to a GitHub repository.
- [ ] Record the actual running app for 2–3 minutes using Loom or Google Drive.
- [ ] Paste your real GitHub and recording links into Internshala.

This archive contains source code, not a pre-recorded video or a published GitHub repository. You must create those links from your own accounts.
